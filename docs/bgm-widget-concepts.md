# BGM 위젯 디자인 구상

실제 음악 위젯과 플레이어 사례에서 반복되는 구성은 정사각 앨범 표지, 곡명·아티스트의 분리,
재생/일시정지, 진행 바, 재생 시간입니다. 큰 위젯에서는 앨범 표지나 LP 자체가 주인공이 되고,
작은 위젯에서는 표지와 핵심 조작만 남기는 방식이 안정적입니다.

## 제안 타입

1. **미니 바**
   - 작은 가로 위젯. 왼쪽 재생 버튼, 가운데 곡명, 아래 얇은 진행 바만 표시합니다.
   - 앨범 표지는 선택 사항이며 1칸 정사각 썸네일로 붙일 수 있습니다.
   - 카테고리와 디데이 사이에 넣기 쉬운 기본형입니다.

2. **커버 플레이어**
   - 왼쪽 또는 위에 정사각 앨범 표지를 크게 두고 곡명, 아티스트, 재생 버튼과 진행 바를 배치합니다.
   - 현재 페어홈에서 가장 범용적인 대표 BGM 위젯으로 사용합니다.
   - 표지는 이미지 프레임과 동일한 확대·초점 위치 기능을 사용합니다.

3. **앨범 카드**
   - 큰 정사각 표지, 곡명, 아티스트, 전체 시간, 이전/재생/다음 모양의 컨트롤을 표시합니다.
   - 첫 구현에서는 한 곡 재생만 지원하므로 이전/다음은 장식으로 두지 않고 숨깁니다.
   - 추후 재생목록 기능을 넣을 때만 이전/다음 버튼을 활성화합니다.

4. **LP 플레이어**
   - 앨범 표지를 중앙 라벨로 사용한 검정 LP와 간단한 톤암을 표시합니다.
   - 재생 중에만 LP가 회전하고 일시정지하면 현재 각도에서 멈춥니다.
   - `prefers-reduced-motion` 환경에서는 회전 애니메이션을 끕니다.

5. **재킷 + 반쪽 LP**
   - 정사각 앨범 재킷 뒤에서 LP가 반쯤 나온 형태입니다.
   - LP 전체 턴테이블보다 작은 공간에 적합하고, 스티커처럼 장식성이 강합니다.
   - 재생 중 LP만 천천히 회전합니다.

6. **커버 배경형**
   - 앨범 표지를 위젯 전체 배경으로 확대하고 어두운 오버레이 또는 블러 위에 정보를 표시합니다.
   - 글래스 테마에서는 반투명 컨트롤, 플랫/라인/굵은 선에서는 단색 정보판을 사용합니다.

7. **레트로 오디오 덱**
   - 도트 테마용 작은 LCD 곡명 창, 픽셀 재생 버튼, 각진 진행 바를 사용합니다.
   - 카세트나 실제 기계 전체를 묘사하기보다 핵심 부품만 단순화해 작은 칸에서도 깨지지 않게 합니다.

## 공통 편집 항목

- 음원 업로드 또는 주소
- 앨범 표지 업로드/제거, 확대, 가로·세로 초점
- 곡명과 아티스트명
- 디자인 타입 선택
- 반복 재생, 기본 음량
- 진행 바·재생 시간·앨범 표지 표시 여부
- 표지 위치: 왼쪽 / 오른쪽 / 위
- LP 회전 속도
- 테마 상속, 테마 색, 테두리 색, 배경색

자동재생은 브라우저 정책 때문에 페이지 진입 즉시 소리가 나지 않을 수 있으므로, 저장 옵션은 제공하더라도
실제 재생 실패 시 사용자의 첫 클릭 이후 시작하도록 처리합니다.

## 구현 상태

- `미니 바`, `커버 플레이어`, `앨범 카드`, `LP 플레이어`, `재킷 + 반쪽 LP`, `커버 배경형`, `레트로 오디오 덱`을 BGM 설정의 표시 형식으로 선택할 수 있습니다.
- 모든 형식이 같은 음원, 앨범 표지, 곡명, 아티스트, 반복 재생, 기본 볼륨 값을 공유합니다.
- 재생 버튼, 탐색 진행 바, 현재 시간과 전체 시간, 볼륨 조절이 실제 오디오 요소와 연결됩니다.
- LP 형식은 재생 중에만 음반이 회전합니다.
- 앨범 표지 확대와 가로·세로 초점을 조절할 수 있고, 일반 커버·LP 중앙 라벨·커버 배경형이 같은 값을 사용합니다.

## 참고한 실제 사례

- [WMG Chords Audio Player](https://chords.wmg.com/dashboard/design-system/audio-player.html): 정사각 앨범 표지와 작은 화면의 컴팩트 플레이어 규칙
- [music-desktop-widget](https://github.com/lgg/music-desktop-widget): 앨범 표지, 진행 상태, 조작부를 여러 레이아웃으로 제공
- [Groove Widget](https://github.com/minianon/Groove-Widget): 커버 블러 배경과 바이닐 애니메이션
- [eVinyl](https://www.behance.net/gallery/36558309/eVinyl-Online-record-store): LP, 톤암, 진행 바를 결합한 턴테이블형 화면
- [Vinyl Player Concept](https://dribbble.com/shots/10484084-Music-App-Vinyl-Player-Concept): 앨범 정보와 트랙 목록을 함께 배치한 큰 플레이어
- [Marquee Player Styles](https://marquee.fm/): LP, 카세트, CD, 이퀄라이저처럼 매체 자체를 위젯 디자인으로 사용하는 사례
