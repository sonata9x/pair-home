# 격자형 페어홈

현재 `main.php`는 30열 × 30행 격자 배치를 사용합니다. 기본 프로필은 가로 5칸으로 배치합니다. 프로필, 이미지 프레임,
텍스트, 카테고리, BGM, 디데이는 정수 칸 좌표와 크기로 저장합니다. 블록은 서로
겹칠 수 없고, 스티커만 백분율 좌표·자유 크기·회전을 사용하며 블록 위에 표시됩니다.
모든 콘텐츠는 본문 안에서 잘립니다. 배경 이미지는 전체 페이지의 가장 아래입니다.

- 드래그: 이동. 오른쪽 아래 손잡이: 크기 조절.
- 방향키: 선택한 블록을 한 칸 이동. Shift + 방향키: 한 칸 크기 조절.
- 스티커 방향키: 0.5% 이동. 스티커 회전·투명도·이미지 비율은 유지합니다.
- 겹치는 위치에 놓거나 포인터 조작이 취소되면 조작 전 위치로 복구합니다.
- 새 블록/복제는 빈 칸을 찾고, 공간이 부족하면 안내합니다.
- 사진 비율이 아닌 **프레임 외곽**이 격자를 따릅니다. 이미지 프레임은 자유 비율과 `1:1`, `2:3`, `3:2`, `3:4`, `4:3`, `9:16`, `16:9` 고정 비율을 제공하며, 고정 비율에서는 해당 가로×세로 칸의 배수로만 크기가 변합니다. 사진은 내부에서 crop/zoom합니다.
- 프로필은 헤더 이미지와 프로필 사진을 독립적으로 업로드/제거하며, 두 이미지의 확대와 가로·세로 초점도 따로 저장합니다. 아이디/짧은 문구와 링크 버튼 문구도 편집할 수 있습니다.
- 카테고리는 아이콘형과 텍스트형을 제공합니다. 프로필 기본 가로폭은 5칸이며, 이를 5등분한 최소 격자 하나가 1칸입니다. 아이콘형은 가로/세로 방향을 고를 수 있고 항목 하나가 1×1칸을 차지하며, 개별 아이콘에는 박스를 씌우지 않고 바 전체에만 테마 박스를 적용합니다. 텍스트형은 아이콘과 외곽 박스 없이 게시판 이름을 한 줄로 나열합니다. 항목 수나 형식을 바꾸면 필요한 크기로 조절하고, 충돌하면 빈 칸으로 이동합니다. 관리자 편집 화면에서는 설치된 그누보드 게시판을 선택해 항목으로 추가할 수 있고, 기존 `이름|주소|아이콘` 직접 입력도 함께 사용할 수 있습니다.
- 사이트 기본 테마는 플랫·라인·굵은 선·소프트·도트·글래스 여섯 종류입니다. 굵은 선은 플랫의 간결한 내부 구성에 기본 검정 2px 테두리만 더합니다. 도트 테마는 Galmuri11 픽셀 폰트, 기본 검정 픽셀 테두리와 가까이 붙는 고정 2px 하드 그림자, 각진 버튼·캘린더 등 픽셀 내부 요소를 사용합니다. 홈페이지 프레임 주소는 별도 검색창 박스 없이 도트 글자로만 표시하고, 창 제어 문자는 박스 없이 픽셀 글리프로, 왼쪽 원은 속이 찬 계단식 픽셀 원으로 표시합니다. 테두리와 그림자는 테두리 색을, 원과 제어 문자는 테마 색을 사용해 두 색을 독립적으로 바꿀 수 있습니다. 위젯은 기본 테마를 상속하거나 다른 테마를 고르고, 테두리 색·굵기·모서리·그림자를 개별로 덮어쓸 수 있습니다. 모든 테마의 테두리 굵기와 그림자는 위젯 칸 크기와 무관한 CSS px 값이라 위젯을 리사이즈하거나 내부 이미지를 확대해도 변하지 않습니다.
- 블록별 테마색·바탕색·카드 글자색은 서로 독립적으로 저장합니다. 텍스트 블록은 기존 글자색 설정을 사용합니다.
- 구분선은 가로/세로와 실선·점선·도트·이중선을 지원합니다.
- 라벨은 사각형·캡슐·탭 형태이며 공통 테마를 사용합니다.
- 연결 배너는 이미지 또는 텍스트로 표시하고 다른 홈을 현재 창이나 새 창으로 연결합니다.
- 캘린더는 현재 달 또는 고정 월을 표시하며 날짜 강조와 이전/다음 달 탐색을 지원합니다.
- 홈페이지 프레임은 맥 웹페이지형 상단바와 하나의 창 본문을 제공합니다. 검색창 표시 여부를 고르고, 본문 전체를 빈 창·이미지·텍스트 메모 중 하나로 사용하거나 둥근 상단바만 남길 수 있습니다. 하나의 독립 위젯이므로 다른 일반 위젯과 겹치지 않습니다.

## 기존 코드 보존

전환 직전의 메인은 `main.legacy.php`에 보존했습니다. 기존 `js/pair-home.js`,
`css/pair-home.css`, `css/pair-home-editor.css`, `lib/pair_home.lib.php`도 남아 있습니다.
기존 테마 화면은 로그인 후 `main.legacy.php?iframe_skip=1`에서 확인할 수 있습니다.

기존 `pair_home_layout`, 배경, 테마 설정은 수정하지 않습니다. 새 배치는 별도 설정
`pair_home_grid_document`에 버전·배경·블록 목록을 한 문서로 저장합니다.
API의 `save_grid`는 기존 관리자/세션 토큰 검증을 재사용합니다. 기존 `save`는 유지합니다.

문서의 `representativeColor`가 사이트 대표색이고 `defaultTheme`이 사이트 기본 테마입니다. 일반 블록의 포인트 색은 기본적으로
대표색을 참조하며, 블록별로 개별 색 또는 그라데이션을 선택할 수 있습니다. 그라데이션의
시작·마지막 색은 각각 대표색 참조/개별 색을 독립적으로 고릅니다.

텍스트 블록은 Pretendard, Noto Sans/Serif KR, IBM Plex Sans KR, 고운돋움/고운바탕,
나눔손글씨 펜을 웹폰트로 불러옵니다. CDN을 불러오지 못하면 시스템 글꼴로 대체됩니다.
기존 이미지·음원 업로드 API도 그대로 재사용합니다. 이미지 프레임과 스티커는 업로드한 이미지만 제거할 수 있으며, BGM 앨범 표지는 확대와 가로·세로 초점을 저장해 커버·LP 라벨·배경형에 일관되게 적용합니다.

## 검증

```text
node --test tests/pair-home-grid.test.cjs
php tests/pair-home-grid.test.php
php -l main.php
php -l lib/pair_home_grid.lib.php
php -l api/pair_home.php
```

화면 검토용 `output/design-review/grid-preview.html`은 샘플 데이터만 사용합니다.
`PHP_BINARY`에 로컬 PHP 실행 경로를 설정하고 `build-grid-preview.cjs`를 실행하면
현재 메인 마크업·기본 배치·실제 스타일과 스크립트를 이용해 다시 생성할 수 있습니다.
브라우저에서 데스크톱 드래그 이동/리사이즈, 겹침 차단, 스티커 자유 이동 및 모바일
본문 경계를 확인했습니다. 로그인 세션이 필요한 실제 DB 저장/업로드는 별도 확인이 필요합니다.
